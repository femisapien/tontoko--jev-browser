# Jev Browser 0.12.2

This patch release fixes a screen-mode issue found in screen-only walkthroughs
on 0.12.1. There are no API or schema changes.

## Fixes

- A screen observation is no longer invalidated by `history.replaceState` or
  `history.pushState` calls that keep the current URL. Frameworks that call
  history.replaceState with the current URL, e.g. on scroll, produce a
  main-frame same-document navigation event without changing the document, the
  address, the scroll position or the viewport. 0.12.1 treated that event as a
  navigation, so the next input after a `scroll` usually failed with
  `STALE_SCREEN`, and an update during capture forced a retake reported as
  `navigated`. Cross-document navigations (including a reload to the same URL)
  and same-document navigations that change the URL, such as `pushState` to
  another path or a hash change, still invalidate the observation.

## Installation

```sh
npm install --save-dev https://github.com/tontoko/jev-browser/releases/download/v0.12.2/tontoko-jev-browser-0.12.2.tgz
npx jev-browser install chromium
```

This is GitHub Release tarball distribution, not an npm registry publication.
Verification and recovery follow the 0.10.0 notes: publication happens from CI
only after every platform job succeeds and never overwrites an existing tag.
