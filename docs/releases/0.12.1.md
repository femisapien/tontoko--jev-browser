# Jev Browser 0.12.1

This patch release fixes two screen-mode issues found in screen-only
walkthroughs on 0.12.0. There are no API or schema changes.

## Fixes

- A screen `scroll` now captures after the scroll settles. Browsers scroll
  asynchronously after a wheel, and smooth scrolling animated by the browser or
  the page can take hundreds of milliseconds, so 0.12.0 could return an image
  of the unscrolled or half-scrolled page and the next input with that
  `observationId` failed with `STALE_SCREEN`. Capture now waits until scroll
  events have stopped for two animation frames, or until none start within
  200 ms, for at most 1.5 seconds and always within the operation budget.
- The screen journal `header` row's `startedAt` now reports when the browser
  session was created. It was previously the time the journal file was first
  written, which is after the first recorded action started.

## Documentation

- A link or form with `target="_blank"` opens a tab that a screen-only session
  cannot see or switch to; the opening page reports `SCREEN_POPUP_UNSUPPORTED`
  while that tab stays open. This was already covered by the new-tab
  capability limit and is now named in `docs/screen-review.md`.

## Installation

```sh
npm install --save-dev https://github.com/tontoko/jev-browser/releases/download/v0.12.1/tontoko-jev-browser-0.12.1.tgz
npx jev-browser install chromium
```

This is GitHub Release tarball distribution, not an npm registry publication.
Verification and recovery follow the 0.10.0 notes: publication happens from CI
only after every platform job succeeds and never overwrites an existing tag.
