# Jev Browser 0.15.1

This patch release fixes `run` failing with HTTP 422 from Clef and other System One endpoints. It has no breaking changes.

## Upgrading from 0.15.0

No code or configuration change is required.

- **No more 422 on pages without inputs.** When `run` diagnoses a blocked goal on a page with no enabled fillable, select or combobox control, it no longer sends the `blocker_field` question. That question had only the `__none__` criterion, and the endpoint requires at least two. The run now stops with `missing-input` or `no-match` instead of `PROVIDER_ERROR`.

## Installation

```sh
npm install --save-dev https://github.com/tontoko/jev-browser/releases/download/v0.15.1/tontoko-jev-browser-0.15.1.tgz
npx jev-browser install chromium
```

npm 7+ and pnpm install the `playwright-core` and `zod` peers automatically;
with Yarn Berry, add them explicitly:
`yarn add -D ./tontoko-jev-browser-0.15.1.tgz playwright-core zod`.

This is GitHub Release tarball distribution, not an npm registry publication.
Verification and recovery follow the 0.10.0 notes: publication happens from CI
only after every platform job succeeds and never overwrites an existing tag.
