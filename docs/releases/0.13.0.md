# Jev Browser 0.13.0

This release shares Playwright and Zod with your project, gives the CLI and
MCP server a smaller default tool surface, tightens a few options that were
silently ignored, and makes screen-only sessions recover from dialogs and
popups. Read the breaking changes before updating a dependency pin.
`docs/migration.md` has the full migration notes under the sections marked
"0.13.0".

## Breaking changes and migration

### Playwright and Zod are peer dependencies

`playwright` and `zod` are no longer bundled. The package now declares the peer
dependencies `playwright-core` `>=1.62.0 <2` and `zod` `^4.2.0`, so a Page
from your own Playwright or `@playwright/test` and a Zod schema from your own
`zod` are the same implementations the SDK uses. Operation cancellation needs
the AbortSignal support added in `playwright-core` 1.62, and
`z.fromJSONSchema` needs Zod 4.2.

- npm 7+ and pnpm install missing peers automatically, choosing the newest
  matching release. To share one `playwright-core` with an older
  `@playwright/test`, pin it to the same version, for example
  `npm install -D playwright-core@1.62.0` next to `@playwright/test@1.62.0`.
- Yarn Berry does not install peers. Add them explicitly:
  `yarn add -D ./tontoko-jev-browser-0.13.0.tgz playwright-core zod`.
- A resolved `playwright-core` older than 1.62 makes `new JevBrowser()` and
  `JevBrowser.launch()` fail with `CONFIG`, naming the version found. Upgrade
  `@playwright/test` to 1.62 or newer.
- `jev-browser install` installs the browser build of your resolved
  `playwright-core`, the same one `npx playwright install` installs.

### CLI/MCP capabilities (`--caps`)

The CLI and MCP server enable these tools only when their capability is listed
in `--caps` (comma-separated or repeated):

| Capability | Tools |
| --- | --- |
| `storage` | `cookies`, `storage`, `storage_state` |
| `network` | `route` |
| `trace` | `trace` |
| `evaluate` | `evaluate`, `init_script` |

A disabled tool is left out of MCP `tools/list`, and the CLI answers
`CAPABILITY_DISABLED`. `--allow-evaluate` still works as an alias for
`--caps evaluate`. `console_messages`, `network_requests` (method, URL without
query and resource type only), `pdf`, `downloads` and screenshots stay enabled.
Add the capabilities you use to your MCP client arguments or CLI `open`
command, for example `--caps storage,network`. The SDK is not gated:
`allowEvaluate` still controls evaluation, and `createMcpServer()` registers
every tool unless you pass its new `capabilities` option.

### CLI/MCP uploads need `--file-root`

`file_upload` in the CLI and MCP server no longer reads from the working
directory by default. Without `--file-root DIR` it fails with
`FILE_ACCESS_DENIED`. Pass a dedicated directory that holds only the files to
upload, or `--file-root .` to restore the previous behavior. The SDK default
(`fileRoots` of the working directory) is unchanged.

### Strict `select_option` values

Native `select_option` with `by: 'value'` matches option values exactly.
Earlier releases also matched an option whose label equalled the string. Omit
`by` to keep value-or-label matching, or pass `by: 'label'`. A value with no
matching option still makes Playwright wait, so the call fails with `TIMEOUT`
when the operation budget ends.

### Named sessions keep their launch options

`open --session NAME` for a running session now fails with
`SESSION_MODE_MISMATCH` when the launch options differ, including `--caps`,
`--allow-evaluate` and `--file-root`, instead of reusing the session and
ignoring the new options. The URL and `--idle-timeout-ms` are not launch
options. Repeat the original options, or `close --session NAME` and open it
again. A session started by an older release records no launch options, so
reopening it with 0.13.0 always fails with `SESSION_MODE_MISMATCH`: close such
sessions after upgrading. Commands other than `open` are unaffected.

### CDP and WebSocket attach with context options

`JevBrowser.launch()` (and the CLI/MCP `--cdp-endpoint` / `--ws-endpoint`)
with `contextOptions` or `storageState` now fails with `CONFIG` when the
attached browser already has a context. Playwright cannot apply them to that
context, and earlier releases ignored them silently. Remove them, or launch a
new browser. When the attached browser has no context, Jev still creates one
with those options.

### Borrowed Pages and file choosers

A `JevBrowser` constructed with a borrowed Page listens for file choosers only
while one of its operations runs, as it already did for dialogs. Between
operations, your own `page.on('filechooser')` handling and a headed browser's
native picker work as usual. Choosers opened during a Jev operation are still
held for `file_upload`. Pass `captureDialogs: true` to also hold dialogs and
file choosers between operations. `JevBrowser.launch()`, the CLI and the MCP
server keep holding them by default.

## Screen-only recovery

- A native dialog in a screen-only session is reported once with
  `SCREEN_DIALOG_UNSUPPORTED` and dismissed, instead of failing every later
  screen call with `DIALOG_PENDING` until a restart.
- A new tab opened by the page, such as a `target="_blank"` link, is reported
  once with `SCREEN_POPUP_UNSUPPORTED` and closed; observations continue on the
  original page.
- `screen` no longer fails with `SCREEN_FAILED` (`unknown`) before Chromium has
  rendered a fresh page's first frame. It waits within the operation budget and
  reports `timeout` if the frame never arrives.

## Observation

- `snapshot`, `observe`, `act`, `extract`, the semantic tools and `run` accept
  per-call `maxElements`, `maxTexts` and `maxCandidates` (clamped to 1000,
  2000 and 2000) and `exclude` CSS selectors, in the SDK, MCP and CLI
  (`--exclude`).
- `scope` also accepts a current snapshot or `semantic_locate` ref and limits
  observation to that element in its own frame; an expired ref fails with
  `STALE_TARGET`.
- Row, list, form and record context strings sent to the decision endpoint no
  longer include text typed into `contenteditable` editors, `<textarea>` and
  `<input>` controls, or native `<select>` option labels. Element names and
  labels are kept.

## Errors and results

- When the selected tab is closed outside a `tabs` command, operations fail
  with the new `TAB_CLOSED` code, which says to pick another tab with `tabs`
  `select`. Jev does not switch tabs by itself.
- `run()` and `resume()` reject an unparsable `scope` with `INVALID_SELECTOR`
  before observing, instead of `RUN_FAILED`.
- A pending `dialog` result includes the `pageId` of the tab that opened it,
  and `downloads` `list` entries include `navigation`, the tab's navigation
  generation when the download started.
- A core keeps at most 32 paused continuations and drops a Page's continuations
  when the Page closes; a dropped ID fails with `CONTINUATION_NOT_FOUND`.
- An empty or whitespace-only `JEV_MODEL` or `--model ""` counts as unset
  instead of sending an empty model name.

## Installation

```sh
npm install --save-dev https://github.com/tontoko/jev-browser/releases/download/v0.13.0/tontoko-jev-browser-0.13.0.tgz
npx jev-browser install chromium
```

npm 7+ and pnpm install the `playwright-core` and `zod` peers automatically;
with Yarn Berry, add them explicitly as shown above.

This is GitHub Release tarball distribution, not an npm registry publication.
Verification and recovery follow the 0.10.0 notes: publication happens from CI
only after every platform job succeeds and never overwrites an existing tag.
