# Jev Browser 0.11.0

## New: `jev-browser install`

`jev-browser install [chromium|firefox|webkit] [--dry-run]` installs the browser
build required by the Playwright version this package bundles. A project that
pins a different Playwright no longer needs to locate this package's Playwright
CLI by hand; running its own `npx playwright install` would fetch a different
build.

No SDK, MCP or screen-mode behavior changes, and no dependency changes.

## Installation

```sh
npm install --save-dev https://github.com/tontoko/jev-browser/releases/download/v0.11.0/tontoko-jev-browser-0.11.0.tgz
npx jev-browser install chromium
```

This is GitHub Release tarball distribution, not an npm registry publication.
Verification and recovery follow the 0.10.0 notes: publication happens from CI
only after every platform job succeeds and never overwrites an existing tag.
